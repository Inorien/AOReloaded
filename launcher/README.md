# AOReloaded

AOReloaded makes the game more comfortable to play: a camera that swings back behind you, running with both mouse
buttons, a smoother autorun, timer bars you can move, and quicker ways to move items and raise skills.

## Using it

There is nothing to start: AOReloaded works in the game once it is installed. Each feature can be switched off.

- **Camera**: drag with the left mouse button to look around; let go and the camera swings back behind you. Hold
  both mouse buttons to run forward.
- **Inventory**: Ctrl+click moves an item to or from the backpack you opened last. Alt+click selects several items,
  and moving one moves them all. Ctrl+Alt+click pins an item to the top of the inventory.
- **Skills**: Shift+click a skill's + or - to change it by 5. Ctrl+Alt+click a skill to add it to Favorites.
- **Timer bars**: drag a cast or action bar while it runs to move it.

## Settings

In the panel's **Options**, under AOReloaded, and in the game's **AOReloaded** tab of the options window (F10).
Changes made in the panel take effect at the next start of the game.
